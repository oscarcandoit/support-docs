## 示例输出

Python

```
def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        yield a
        a, b = b, a + b
```

解释：使用带有yield的生成器函数对于生成斐波那契数列更节省内存。它避免了在列表中创建和存储整个序列。相反，它根据需要即时生成每个数字。
