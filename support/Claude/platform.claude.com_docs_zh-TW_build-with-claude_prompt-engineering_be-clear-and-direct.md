# 清晰、直接且詳細

Copy page

學習如何以清晰、直接且詳細的方式與 Claude 互動，以獲得最佳結果。

Copy page

While these tips apply broadly to all Claude models, you can find prompting tips specific to extended thinking models [here](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/extended-thinking-tips).

與 Claude 互動時，可以把它想像成一位才華橫溢但剛入職（患有失憶症）的員工，需要明確的指示。就像任何新員工一樣，Claude 對你的規範、風格、指南或偏好的工作方式沒有背景知識。
你解釋得越精確，Claude 的回應就會越好。

**清晰提示的黃金法則**

將你的提示詞展示給同事看，最好是對該任務背景知識最少的人，並要求他們按照指示進行。如果他們感到困惑，Claude 也很可能會困惑。

## 如何做到清晰、有背景且具體

- **向 Claude 提供背景資訊：**就像你在了解更多背景資訊的情況下能更好地完成任務一樣，Claude 在擁有更多背景資訊時也會表現得更好。背景資訊的一些例子包括：
  - 任務結果將被用於什麼目的
  - 輸出內容的目標受眾是誰
  - 該任務是工作流程的哪一部分，以及該任務在工作流程中的位置
  - 任務的最終目標，或成功完成任務的樣子
- **具體說明你希望 Claude 做什麼：** 例如，如果你希望 Claude 只輸出代碼而不輸出其他任何內容，請明確說明。
- **以順序步驟提供指示：** 使用編號列表或項目符號，以更好地確保 Claude 按照你想要的方式執行任務。
