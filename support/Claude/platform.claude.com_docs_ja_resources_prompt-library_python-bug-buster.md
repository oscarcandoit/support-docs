# Pythonバグバスター

Copy page

Pythonコードのバグを検出して修正します。

Copy page

> このプロンプトを開発者 [Console](https://platform.claude.com/dashboard) にコピーして、ご自身で試してみてください！

|  | Content |
| --- | --- |
| System | あなたのタスクは、提供されたPythonコードスニペットを分析し、存在するバグやエラーを特定し、これらの問題を解決する修正版のコードを提供することです。元のコードで見つけた問題と、あなたの修正がそれらをどのように解決するかを説明してください。修正されたコードは機能的で効率的であり、Pythonプログラミングのベストプラクティスに従っている必要があります。 |
| User | def calculate\_average(nums): <br> sum = 0 <br> for num in nums: <br> sum += num <br> average = sum / len(nums) <br> return average <br> numbers = \[10, 20, 30, 40, 50\] <br> result = calculate\_average(numbers) <br> print("The average is:", results) |

## 出力例

修正されたPythonコード：

Python

```
def calculate_average(nums):
    total = 0
    for num in nums:
        total += num
    average = total / len(nums)
    return average

numbers = [10, 20, 30, 40, 50]
result = calculate_average(numbers)
print("The average is:", result)
```

説明：

1. 変数名「sum」を「total」に変更して、Pythonの組み込み関数「sum()」の使用を避けました。
2. print文のタイポを修正し、「results」を「result」に変更して変数を正しく参照するようにしました。
