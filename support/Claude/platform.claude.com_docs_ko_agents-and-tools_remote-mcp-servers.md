# 원격 MCP 서버

Copy page

원격 MCP 서버에 대한 정보

Copy page

여러 회사들이 개발자들이 Anthropic MCP 커넥터 API를 통해 연결할 수 있는 원격 MCP 서버를 배포했습니다. 이러한 서버들은 MCP 프로토콜을 통해 다양한 서비스와 도구에 대한 원격 액세스를 제공함으로써 개발자와 최종 사용자가 사용할 수 있는 기능을 확장합니다.

아래에 나열된 원격 MCP 서버들은 Claude API와 함께 작동하도록 설계된 제3자 서비스입니다. 이러한 서버들은
Anthropic이 소유, 운영 또는 승인하지 않습니다. 사용자는 신뢰할 수 있는 원격 MCP 서버에만 연결해야 하며
연결하기 전에 각 서버의 보안 관행과 약관을 검토해야 합니다.

## 원격 MCP 서버에 연결하기

원격 MCP 서버에 연결하려면:

1. 사용하려는 특정 서버에 대한 문서를 검토하세요.
2. 필요한 인증 자격 증명이 있는지 확인하세요.
3. 각 회사에서 제공하는 서버별 연결 지침을 따르세요.

Claude API와 함께 원격 MCP 서버를 사용하는 방법에 대한 자세한 정보는 [MCP 커넥터 문서](https://platform.claude.com/docs/ko/agents-and-tools/mcp-connector) 를 참조하세요.
