# 多語言支援

Copy page

Claude 在多種語言的任務中表現出色，相對於英文保持強大的跨語言性能。

Copy page

## 概述

Claude 展示了強大的多語言能力，特別是在跨語言的零樣本任務中表現出色。該模型在廣泛使用的語言和低資源語言中都保持一致的相對性能，使其成為多語言應用的可靠選擇。

請注意，Claude 能夠使用許多超出下面基準測試的語言。我們鼓勵您使用與您特定用例相關的任何語言進行測試。

這些指標基於 [MMLU (大規模多任務語言理解)](https://en.wikipedia.org/wiki/MMLU) 英文測試集，由專業人工翻譯人員翻譯成 14 種其他語言，如 [OpenAI 的 simple-evals 儲存庫](https://github.com/openai/simple-evals/blob/main/multilingual_mmlu_benchmark_results.md) 所記錄。使用人工翻譯人員進行此評估可確保高品質的翻譯，這對於數位資源較少的語言尤其重要。

* * *

## 最佳實踐

使用多語言內容時：

1. **提供清晰的語言背景**：雖然 Claude 可以自動偵測目標語言，但明確說明所需的輸入/輸出語言會提高可靠性。為了增強流暢性，您可以提示 Claude 使用「如同母語使用者般的習慣用語」。
2. **使用原生文字**：以原生文字而非音譯方式提交文本以獲得最佳結果
3. **考慮文化背景**：有效的溝通通常需要超越純粹翻譯的文化和地區意識

我們也建議遵循我們的一般 [提示工程指南](https://platform.claude.com/docs/zh-TW/build-with-claude/prompt-engineering/overview) 以更好地改進 Claude 的性能。

* * *

## 語言支援考量

- Claude 可以處理使用標準 Unicode 字元的大多數世界語言的輸入並生成輸出
- 性能因語言而異，在廣泛使用的語言中具有特別強大的能力
- 即使在數位資源較少的語言中，Claude 也能保持有意義的能力
