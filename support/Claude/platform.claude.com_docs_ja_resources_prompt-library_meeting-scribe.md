# 会議書記

Copy page

会議を議論トピック、重要なポイント、アクションアイテムを含む簡潔な要約に整理します。

Copy page

> このプロンプトを私たちの開発者 [Console](https://platform.claude.com/dashboard) にコピーして、ご自身で試してみてください！

|  | Content |
| --- | --- |
| System | あなたのタスクは、提供された会議メモを確認し、重要な情報を捉える簡潔な要約を作成することです。会議中に特定の個人や部門に割り当てられた重要なポイントとアクションアイテムに焦点を当ててください。明確で専門的な言語を使用し、見出し、小見出し、箇条書きなどの適切な書式を使用して論理的な方法で要約を整理してください。要約が理解しやすく、会議内容の包括的かつ簡潔な概要を提供し、特に各アクションアイテムの責任者を明確に示すことに重点を置いてください。 |
| User | 会議メモ: <br> 日付: イタリア、ヴェローナ \- 16世紀後期 <br> 出席者: <br> \- キャピュレット卿（キャピュレット家の当主） <br> \- モンタギュー卿（モンタギュー家の当主） <br> \- エスカラス公（ヴェローナの統治者） <br> \- ローレンス修道士（宗教的顧問） <br> 議題: <br> 1\. キャピュレット家とモンタギュー家の間の継続的な確執に対処する <br> 2\. ロミオ・モンタギューとジュリエット・キャピュレットの秘密結婚について議論する <br> 3\. ヴェローナに平和をもたらす計画を策定する <br> 4\. ロミオとジュリエットの悲劇的な死に対処する <br> 議論: <br> \- エスカラス公は、キャピュレット家とモンタギュー家の間の長年の確執に対する深刻な懸念を表明して会議を開始しました。彼は、ヴェローナの街の平和を乱した最近の暴力的な衝突について、キャピュレット卿とモンタギュー卿の両方を叱責しました。公は、さらなる暴力は重い罰金や加害者の追放の可能性を含む深刻な結果をもたらすと警告しました。 <br> \- ローレンス修道士は次に、彼の指導の下で行われたロミオ・モンタギューとジュリエット・キャピュレットの間の結婚の話題を持ち出しました。キャピュレット卿とモンタギュー卿は明らかにそれについて知らず、怒りと不信で反応しました。しかし、ローレンス修道士は、彼らの子供たちが共有した深遠で悲劇的な愛と、この愛が今後家族間の亀裂を癒す可能性を考慮するよう彼らに促しました。 <br> \- エスカラス公は、キャピュレット家とモンタギュー家の間の正式な休戦を提案しました。彼は両陣営が武器を置き、互いに対するすべての敵対行為を停止することを要求しました。公は、休戦の違反は追放や処刑の可能性を含む厳しい処罰をもたらすと宣言しました。キャピュレット卿とモンタギュー卿は、公の言葉の知恵と、家族と都市の福祉のための平和の必要性を認識し、しぶしぶ休戦の条件に同意しました。 <br> \- ロミオとジュリエットの悲劇的な死が取り上げられると、会議は厳粛な雰囲気になりました。ローレンス修道士は、若い恋人たちが自らの命を絶つに至った不幸な一連の出来事を語り、家族の憎悪が無実の子供たちに与えた壊滅的な影響を強調しました。キャピュレット卿とモンタギュー卿は、悲しみと後悔に圧倒され、彼らの盲目的な憎悪が最終的に愛する子供たちの死を引き起こしたことを認めました。 <br>\- エスカラス公は、この心を痛める悲劇から学び、ロミオとジュリエットの記憶を称えて許しと団結を受け入れるよう家族に呼びかけました。彼は、長年の敵意を脇に置いて、ヴェローナに永続的な平和を創造するために協力するよう彼らに促しました。ローレンス修道士は、将来の紛争の仲裁と、家族が癒され前進するのを助ける精神的指導の提供において彼の支援を申し出ました。 <br>\- 会議が終わりに近づくと、キャピュレット卿とモンタギュー卿は確執を終わらせ、和解に向けて取り組むことを誓いました。エスカラス公は、休戦が維持されることを確実にするという彼のコミットメントを再確認し、それを破る者に対する迅速な正義を約束しました。 <br>\- 出席者は、和解努力の進捗を議論し、発生する可能性のある課題に対処するために定期的に会合することに合意しました。 |

## 出力例

会議要約: ヴェローナの和解と平和
日付: 16世紀後期、イタリア、ヴェローナ

出席者:

- キャピュレット卿（キャピュレット家の当主）
- モンタギュー卿（モンタギュー家の当主）
- エスカラス公（ヴェローナの統治者）
- ローレンス修道士（宗教的顧問）

重要なポイント:

- エスカラス公は、キャピュレット家とモンタギュー家の間の継続的な確執に対処し、さらなる暴力に対する深刻な結果を警告しました。
- ローレンス修道士は、ロミオ・モンタギューとジュリエット・キャピュレットの秘密結婚を明かし、彼らの愛が亀裂を癒す可能性を考慮するよう家族に促しました。
- エスカラス公は、家族間の正式な休戦を提案し、違反に対する厳しい処罰を脅しました。
- ロミオとジュリエットの悲劇的な死が議論され、キャピュレット卿とモンタギュー卿は心を痛める結果における彼らの役割を認めました。
- エスカラス公は、ロミオとジュリエットの記憶を称えて許しと団結を求め、ヴェローナの永続的な平和のために家族が協力するよう促しました。

アクションアイテム:

- キャピュレット卿とモンタギュー卿:
  - 武器を置き、互いに対するすべての敵対行為を停止する。
  - 和解に向けて取り組み、許しを受け入れる。
  - 進捗を議論し、課題に対処するための定期的な会合に出席する。
- エスカラス公:
  - 休戦を執行し、その遵守を確実にする。
  - 休戦違反に対する迅速な正義を執行する。
- ローレンス修道士:
  - 家族の癒しと和解プロセスを支援するための仲裁と精神的指導を提供する。

次のステップ:

- 出席者は、和解努力の進捗を監視し、発生する課題に対処するために定期的に会合します。
