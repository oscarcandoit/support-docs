# 清晰、直接和详细

Copy page

学习如何以清晰、直接和详细的方式与Claude交互，以获得最佳结果

Copy page

While these tips apply broadly to all Claude models, you can find prompting tips specific to extended thinking models [here](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/extended-thinking-tips).

在与Claude交互时，可以把它看作一个聪慧但非常新的员工（患有失忆症），需要明确的指示。像任何新员工一样，Claude没有关于你的规范、风格、指南或首选工作方式的背景信息。
你解释想要的内容越精确，Claude的回应就会越好。

**清晰提示的黄金法则**

将你的提示展示给一位同事，最好是对该任务背景了解最少的人，并要求他们遵循指示。如果他们感到困惑，Claude也可能会困惑。

## 如何做到清晰、有背景和具体

- **为Claude提供背景信息：**就像你在了解更多背景信息的情况下可能能更好地完成任务一样，如果Claude拥有更多背景信息，它的表现也会更好。一些背景信息的例子：
  - 任务结果将被用于什么
  - 输出的目标受众是谁
  - 该任务属于什么工作流程，以及该任务在该工作流程中的位置
  - 任务的最终目标，或成功完成任务的样子
- **具体说明你想让Claude做什么：** 例如，如果你想让Claude只输出代码而不输出其他内容，请明确说明。
- **将指示作为顺序步骤提供：** 使用编号列表或项目符号列表，以更好地确保Claude完全按照你想要的方式执行任务。
