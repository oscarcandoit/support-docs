# Transmissões da Babel

Copy page

Crie tweets cativantes de anúncio de produto nas 10 línguas mais faladas do mundo.

Copy page

> Copie este prompt para o nosso [Console](https://platform.claude.com/dashboard) de desenvolvedor para experimentar você mesmo!

|  | Conteúdo |
| --- | --- |
| Usuário | Escreva-me uma série de tweets de anúncio de produto nas 10 línguas mais comumente faladas. O produto é um novo par de binóculos de última geração com sistemas de IA integrados para identificar os animais vistos através dos binóculos. Os tweets devem ser emocionantes, de ponta e despertar o interesse do consumidor. |
| Usuário | Um futuro onde os humanos podem carregar sua consciência em um reino digital. |

### Solicitação da API

Python

```
import anthropic

client = anthropic.Anthropic(
    # padrão para os.environ.get("ANTHROPIC_API_KEY")
    api_key="my_api_key",
)
message = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=2000,
    temperature=0,
    messages=[\
        {\
            "role": "user",\
            "content": [\
                {\
                    "type": "text",\
                    "text": "Escreva-me uma série de tweets de anúncio de produto nas 10 línguas mais comumente faladas. O produto é um novo par de binóculos de última geração com sistemas de IA integrados para identificar os animais vistos através dos binóculos. Os tweets devem ser emocionantes, de ponta e despertar o interesse do consumidor."\
                }\
            ]\
        }\
    ]
)
print(message.content)
```
