# Geração de texto

Copy page

Claude se destaca em uma ampla gama de tarefas baseadas em texto. Claude foi treinado para processar código, prosa e outras entradas de linguagem natural, e fornecer saídas de texto em resposta.

Copy page

Os prompts são melhor escritos como consultas em linguagem natural, como se você estivesse instruindo alguém a fazer algo, sendo que quanto mais detalhes, melhor. Você pode melhorar ainda mais seu prompt básico com [engenharia de prompts](https://platform.claude.com/docs/pt-BR/build-with-claude/prompt-engineering/overview).

* * *

## Capacidades de texto e casos de uso

Claude tem uma ampla gama de capacidades baseadas em texto, incluindo, mas não se limitando a:

| Capacidade | Isso permite que você... |
| --- | --- |
| Resumo de Texto | Destile conteúdo extenso em insights-chave para executivos, mídias sociais ou equipes de produto. |
| Geração de Conteúdo | Crie conteúdo atraente desde posts de blog e e-mails até slogans de marketing e descrições de produtos. |
| Extração de Dados / Entidades | Descubra insights estruturados a partir de texto não estruturado como avaliações, artigos de notícias ou transcrições. |
| Resposta a Perguntas | Construa sistemas inteligentes e interativos desde chatbots de suporte ao cliente até tutores de IA educacionais. |
| Tradução de Texto | Comunique-se perfeitamente entre idiomas em produtos, suporte e criação de conteúdo. |
| Análise de Texto e Recomendações | Entenda sentimentos, preferências e padrões para personalizar experiências e ofertas do usuário. |
| Diálogo e Conversação | Crie interações envolventes e conscientes do contexto em jogos, assistentes virtuais e aplicativos de narrativa. |
| Explicação e Geração de Código | Acelere o desenvolvimento com revisões instantâneas de código, geração de código padrão e tutoriais interativos. |
