# Claude 소개

Copy page

Claude는 Anthropic이 만든 고성능, 신뢰할 수 있고 지능형 AI 플랫폼입니다. Claude는 언어, 추론, 분석, 코딩 등과 관련된 작업에서 뛰어납니다.

Copy page

The latest generation of Claude models:

**Claude Opus 4.5** \- Most intelligent model, and an industry-leader for coding,
agents, and computer use. [Learn more](https://www.anthropic.com/news/claude-opus-4-5).

**Claude Sonnet 4.5** \- Balanced performance and practicality for most uses,
including coding and agents. [Learn\\
more](https://www.anthropic.com/news/claude-sonnet-4-5).

**Claude Haiku 4.5** \- Fastest model with near-frontier intelligence. [Learn more](https://www.anthropic.com/news/claude-haiku-4-5).

Claude와 채팅하고 싶으신가요? [claude.ai](http://www.claude.ai/) 를 방문하세요!

## Claude로 개발하기

Anthropic은 Claude로 확장 가능한 애플리케이션을 빌드하기 위한 동급 최고의 개발자 도구를 보유하고 있습니다.

[개발자 콘솔\\
\\
Workbench와 프롬프트 생성기 도구를 사용하여 브라우저에서 더 쉽고 강력한 프롬프팅을 즐기세요.](https://platform.claude.com/) [API 참조\\
\\
Claude API 및 SDK를 탐색, 구현 및 확장하세요.](https://platform.claude.com/docs/ko/api/overview) [Claude Cookbook\\
\\
PDF 업로드, 임베딩 등을 시연하는 대화형 Jupyter 노트북으로 배우세요.](https://github.com/anthropics/anthropic-cookbook)

## 주요 기능

Claude는 텍스트, 코드 및 이미지와 관련된 많은 작업을 지원할 수 있습니다.

[텍스트 및 코드 생성\\
\\
텍스트를 요약하고, 질문에 답하고, 데이터를 추출하고, 텍스트를 번역하고, 코드를 설명하고 생성하세요.](https://platform.claude.com/docs/ko/build-with-claude/text-generation) [비전\\
