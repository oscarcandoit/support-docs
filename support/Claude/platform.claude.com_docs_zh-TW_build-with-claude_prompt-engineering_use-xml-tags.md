# 使用 XML 標籤來結構化您的提示詞

Copy page

了解如何使用 XML 標籤來改進提示詞的結構和清晰度，幫助 Claude 更準確地解析您的請求。

Copy page

While these tips apply broadly to all Claude models, you can find prompting tips specific to extended thinking models [here](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/extended-thinking-tips).

當您的提示詞涉及多個組件（如上下文、指令和範例）時，XML 標籤可以改變遊戲規則。它們幫助 Claude 更準確地解析您的提示詞，從而產生更高品質的輸出。

**XML 提示**：使用 `<instructions>`、`<example>` 和 `<formatting>` 等標籤來清楚地分隔提示詞的不同部分。這可以防止 Claude 將指令與範例或上下文混淆。

## 為什麼使用 XML 標籤？

- **清晰度：** 清楚地分隔提示詞的不同部分，並確保您的提示詞結構良好。
- **準確性：** 減少由 Claude 誤解提示詞部分而造成的錯誤。
- **靈活性：** 輕鬆找到、新增、移除或修改提示詞的部分，無需重寫所有內容。
- **可解析性：** 讓 Claude 在其輸出中使用 XML 標籤，可以更輕鬆地通過後處理提取其回應的特定部分。

沒有規範的「最佳」XML 標籤是 Claude 特別訓練過的，儘管我們建議您的標籤名稱應與其周圍的資訊相符。

* * *

## 標籤最佳實踐

1. **保持一致**：在整個提示詞中使用相同的標籤名稱，並在談論內容時參考這些標籤名稱（例如，`使用 <contract> 標籤中的合約...`）。
2. **嵌套標籤**：您應該為分層內容嵌套標籤 `<outer><inner></inner></outer>`。

**進階使用者提示**：將 XML 標籤與其他技術結合，如多次提示（`<examples>`）或思維鏈（`<thinking>`、`<answer>`）。這會建立超級結構化、高效能的提示詞。
