# 모델 개요

Copy page

Claude는 Anthropic에서 개발한 최첨단 대규모 언어 모델 제품군입니다. 이 가이드는 당사의 모델을 소개하고 성능을 비교합니다.

Copy page

## 모델 선택하기

어떤 모델을 사용할지 확실하지 않다면 **Claude Sonnet 4.5** 부터 시작하는 것을 권장합니다. 대부분의 사용 사례에서 지능, 속도, 비용의 최적 균형을 제공하며, 코딩 및 에이전트 작업에서 뛰어난 성능을 발휘합니다.

현재의 모든 Claude 모델은 텍스트 및 이미지 입력, 텍스트 출력, 다국어 기능 및 비전을 지원합니다. 모델은 Anthropic API, AWS Bedrock 및 Google Vertex AI를 통해 사용할 수 있습니다.

모델을 선택한 후 [첫 번째 API 호출을 만드는 방법을 알아보세요](https://platform.claude.com/docs/ko/get-started).

_1 - 별칭은 자동으로 가장 최근의 모델 스냅샷을 가리킵니다. 새로운 모델 스냅샷을 출시할 때 별칭을 새 버전의 모델을 가리키도록 마이그레이션하며, 일반적으로 새 출시 후 1주일 이내에 진행됩니다. 별칭은 실험에 유용하지만 프로덕션 애플리케이션에서는 일관된 동작을 보장하기 위해 특정 모델 버전(예: `claude-sonnet-4-5-20250929`)을 사용하는 것을 권장합니다._

_2 - 배치 API 할인, 프롬프트 캐싱 요금, 확장 사고 비용 및 비전 처리 수수료를 포함한 완전한 가격 정보는 당사의 [가격 페이지](https://platform.claude.com/docs/ko/about-claude/pricing) 를 참조하세요._

_3 - Claude Sonnet 4.5는 `context-1m-2025-08-07` 베타 헤더를 사용할 때 [1M 토큰 컨텍스트 윈도우](https://platform.claude.com/docs/ko/build-with-claude/context-windows#1m-token-context-window) 를 지원합니다. [장문 컨텍스트 가격](https://platform.claude.com/docs/ko/about-claude/pricing#long-context-pricing) 은 200K 토큰을 초과하는 요청에 적용됩니다._

_4 - **신뢰할 수 있는 지식 기준일** 은 모델의 지식이 가장 광범위하고 신뢰할 수 있는 날짜를 나타냅니다. **학습 데이터 기준일** 은 사용된 학습 데이터의 더 넓은 날짜 범위입니다. 예를 들어 Claude Sonnet 4.5는 2025년 7월까지 공개적으로 이용 가능한 정보로 학습되었지만 그 지식은 2025년 1월까지 가장 광범위하고 신뢰할 수 있습니다. 자세한 내용은 [Anthropic의 투명성 허브](https://www.anthropic.com/transparency) 를 참조하세요._

동일한 스냅샷 날짜(예: 20240620)를 가진 모델은 모든 플랫폼에서 동일하며 변경되지 않습니다. 모델 이름의 스냅샷 날짜는 일관성을 보장하고 개발자가 다양한 환경에서 안정적인 성능에 의존할 수 있도록 합니다.

**Claude Sonnet 4.5 및 모든 향후 모델** 부터 AWS Bedrock 및 Google Vertex AI는 두 가지 엔드포인트 유형을 제공합니다: **글로벌 엔드포인트**(최대 가용성을 위한 동적 라우팅) 및 **지역 엔드포인트**(특정 지리적 영역을 통한 보장된 데이터 라우팅). 자세한 내용은 [타사 플랫폼 가격 섹션](https://platform.claude.com/docs/ko/about-claude/pricing#third-party-platform-pricing) 을 참조하세요.

### 레거시 모델

## 프롬프트 및 출력 성능

Claude 4 모델은 다음 분야에서 탁월합니다:

- **성능**: 추론, 코딩, 다국어 작업, 장문 컨텍스트 처리, 정직성 및 이미지 처리에서 최고 수준의 결과를 제공합니다. 자세한 내용은 [Claude 4 블로그 게시물](http://www.anthropic.com/news/claude-4) 을 참조하세요.

- **매력적인 응답**: Claude 모델은 풍부하고 인간다운 상호작용이 필요한 애플리케이션에 이상적입니다.
  - 더 간결한 응답을 선호하는 경우 프롬프트를 조정하여 모델을 원하는 출력 길이로 안내할 수 있습니다. 자세한 내용은 당사의 [프롬프트 엔지니어링 가이드](https://platform.claude.com/docs/ko/build-with-claude/prompt-engineering) 를 참조하세요.
  - Claude 4 프롬프팅 모범 사례는 당사의 [Claude 4 모범 사례 가이드](https://platform.claude.com/docs/ko/build-with-claude/prompt-engineering/claude-4-best-practices) 를 참조하세요.
- **출력 품질**: 이전 모델 세대에서 Claude 4로 마이그레이션할 때 전반적인 성능에서 더 큰 개선을 알 수 있습니다.


## Claude 4.5로 마이그레이션

현재 Claude 3 모델을 사용 중이라면 향상된 지능과 강화된 기능을 활용하기 위해 Claude 4.5로 마이그레이션하는 것을 권장합니다. 자세한 마이그레이션 지침은 [Claude 4.5로 마이그레이션](https://platform.claude.com/docs/ko/about-claude/models/migrating-to-claude-4) 을 참조하세요.
