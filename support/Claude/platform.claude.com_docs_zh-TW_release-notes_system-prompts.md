# 系統提示

Copy page

查看 [Claude.ai](https://www.claude.ai/) 以及 Claude [iOS](http://anthropic.com/ios) 和 [Android](http://anthropic.com/android) 應用程式上核心系統提示的更新。

Copy page

Claude 的網頁介面 ( [Claude.ai](https://www.claude.ai/)) 和行動應用程式使用系統提示在每次對話開始時向 Claude 提供最新資訊，例如目前日期。我們也使用系統提示來鼓勵某些行為，例如始終以 Markdown 格式提供程式碼片段。隨著我們持續改進 Claude 的回應，我們會定期更新此提示。這些系統提示更新不適用於 Anthropic API。版本之間的更新以粗體顯示。
