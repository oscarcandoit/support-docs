## Capacità principali

Queste funzionalità migliorano le abilità fondamentali di Claude per l'elaborazione, l'analisi e la generazione di contenuti in vari formati e casi d'uso.

| Funzionalità | Descrizione | Disponibilità |
| --- | --- | --- |
| [Finestra di contesto da 1M token](https://platform.claude.com/docs/it/build-with-claude/context-windows#1m-token-context-window) | Una finestra di contesto estesa che ti consente di elaborare documenti molto più grandi, mantenere conversazioni più lunghe e lavorare con basi di codice più estese. | Claude API (Beta)<br>Amazon Bedrock (Beta)<br>Google Cloud's Vertex AI (Beta)<br>Microsoft Foundry (Beta) |
| [Agent Skills](https://platform.claude.com/docs/it/agents-and-tools/agent-skills/overview) | Estendi le capacità di Claude con Skills. Utilizza Skills pre-costruiti (PowerPoint, Excel, Word, PDF) o crea Skills personalizzati con istruzioni e script. Le Skills utilizzano la divulgazione progressiva per gestire in modo efficiente il contesto. | Claude API (Beta)<br>Microsoft Foundry (Beta) |
| [Elaborazione batch](https://platform.claude.com/docs/it/build-with-claude/batch-processing) | Elabora grandi volumi di richieste in modo asincrono per risparmiare sui costi. Invia batch con un gran numero di query per batch. Le chiamate API batch costano il 50% in meno rispetto alle chiamate API standard. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI |
| [Citazioni](https://platform.claude.com/docs/it/build-with-claude/citations) | Basa le risposte di Claude su documenti di origine. Con le Citazioni, Claude può fornire riferimenti dettagliati alle frasi e ai passaggi esatti che utilizza per generare risposte, portando a output più verificabili e affidabili. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Modifica del contesto](https://platform.claude.com/docs/it/build-with-claude/context-editing) | Gestisci automaticamente il contesto della conversazione con strategie configurabili. Supporta la cancellazione dei risultati degli strumenti quando ci si avvicina ai limiti di token e la gestione dei blocchi di pensiero nelle conversazioni di pensiero esteso. | Claude API (Beta)<br>Amazon Bedrock (Beta)<br>Google Cloud's Vertex AI (Beta)<br>Microsoft Foundry (Beta) |
| [Effort](https://platform.claude.com/docs/it/build-with-claude/effort) | Controlla quanti token Claude utilizza quando risponde con il parametro effort, scambiando tra la completezza della risposta e l'efficienza dei token. | Claude API (Beta)<br>Amazon Bedrock (Beta)<br>Google Cloud's Vertex AI (Beta)<br>Microsoft Foundry (Beta) |
| [Pensiero esteso](https://platform.claude.com/docs/it/build-with-claude/extended-thinking) | Capacità di ragionamento migliorate per compiti complessi, fornendo trasparenza nel processo di pensiero passo dopo passo di Claude prima di fornire la sua risposta finale. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [API Files](https://platform.claude.com/docs/it/build-with-claude/files) | Carica e gestisci file da utilizzare con Claude senza ricaricare il contenuto ad ogni richiesta. Supporta file PDF, immagini e file di testo. | Claude API (Beta)<br>Microsoft Foundry (Beta) |
| [Supporto PDF](https://platform.claude.com/docs/it/build-with-claude/pdf-support) | Elabora e analizza il contenuto testuale e visivo da documenti PDF. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Prompt caching (5m)](https://platform.claude.com/docs/it/build-with-claude/prompt-caching) | Fornisci a Claude più conoscenze di base e output di esempio per ridurre i costi e la latenza. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Prompt caching (1hr)](https://platform.claude.com/docs/it/build-with-claude/prompt-caching#1-hour-cache-duration) | Durata della cache estesa di 1 ora per il contesto meno frequentemente accessibile ma importante, complementare alla cache standard di 5 minuti. | Claude API<br>Microsoft Foundry |
| [Risultati di ricerca](https://platform.claude.com/docs/it/build-with-claude/search-results) | Abilita citazioni naturali per applicazioni RAG fornendo risultati di ricerca con corretta attribuzione della fonte. Ottieni citazioni di qualità ricerca web per basi di conoscenza personalizzate e strumenti. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Output strutturati](https://platform.claude.com/docs/it/build-with-claude/structured-outputs) | Garantisci la conformità dello schema con due approcci: output JSON per risposte di dati strutturati e uso rigoroso degli strumenti per input degli strumenti convalidati. Disponibile su Sonnet 4.5, Opus 4.1, Opus 4.5 e Haiku 4.5. | Claude API (Beta)<br>Microsoft Foundry (Beta) |
| [Conteggio dei token](https://platform.claude.com/docs/it/api/messages-count-tokens) | Il conteggio dei token ti consente di determinare il numero di token in un messaggio prima di inviarlo a Claude, aiutandoti a prendere decisioni consapevoli sui tuoi prompt e sull'utilizzo. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Uso degli strumenti](https://platform.claude.com/docs/it/agents-and-tools/tool-use/overview) | Consenti a Claude di interagire con strumenti e API esterni per eseguire una varietà più ampia di attività. Per un elenco degli strumenti supportati, vedi [la tabella Strumenti](https://platform.claude.com/docs/it/build-with-claude/overview#tools). | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |

## Strumenti

Queste funzionalità consentono a Claude di interagire con sistemi esterni, eseguire codice e eseguire attività automatizzate attraverso varie interfacce di strumenti.

| Funzionalità | Descrizione | Disponibilità |
| --- | --- | --- |
| [Bash](https://platform.claude.com/docs/it/agents-and-tools/tool-use/bash-tool) | Esegui comandi e script bash per interagire con la shell del sistema e eseguire operazioni da riga di comando. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Esecuzione del codice](https://platform.claude.com/docs/it/agents-and-tools/tool-use/code-execution-tool) | Esegui codice Python in un ambiente sandbox per l'analisi avanzata dei dati. | Claude API (Beta)<br>Microsoft Foundry (Beta) |
| [Chiamata programmatica degli strumenti](https://platform.claude.com/docs/it/agents-and-tools/tool-use/programmatic-tool-calling) | Consenti a Claude di chiamare i tuoi strumenti in modo programmatico da contenitori di esecuzione del codice, riducendo la latenza e il consumo di token per flussi di lavoro multi-strumento. | Claude API (Beta)<br>Microsoft Foundry (Beta) |
| [Uso del computer](https://platform.claude.com/docs/it/agents-and-tools/tool-use/computer-use-tool) | Controlla le interfacce del computer acquisendo schermate e emettendo comandi del mouse e della tastiera. | Claude API (Beta)<br>Amazon Bedrock (Beta)<br>Google Cloud's Vertex AI (Beta)<br>Microsoft Foundry (Beta) |
| [Streaming degli strumenti a grana fine](https://platform.claude.com/docs/it/agents-and-tools/tool-use/fine-grained-tool-streaming) | Trasmetti i parametri di uso degli strumenti senza buffering/convalida JSON, riducendo la latenza per la ricezione di parametri di grandi dimensioni. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Connettore MCP](https://platform.claude.com/docs/it/agents-and-tools/mcp-connector) | Connettiti a server [MCP](https://platform.claude.com/docs/it/mcp) remoti direttamente dall'API Messages senza un client MCP separato. | Claude API (Beta)<br>Microsoft Foundry (Beta) |
| [Memoria](https://platform.claude.com/docs/it/agents-and-tools/tool-use/memory-tool) | Consenti a Claude di archiviare e recuperare informazioni tra conversazioni. Costruisci basi di conoscenza nel tempo, mantieni il contesto del progetto e impara dalle interazioni passate. | Claude API (Beta)<br>Amazon Bedrock (Beta)<br>Google Cloud's Vertex AI (Beta)<br>Microsoft Foundry (Beta) |
| [Editor di testo](https://platform.claude.com/docs/it/agents-and-tools/tool-use/text-editor-tool) | Crea e modifica file di testo con un'interfaccia editor di testo integrata per attività di manipolazione dei file. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Ricerca degli strumenti](https://platform.claude.com/docs/it/agents-and-tools/tool-use/tool-search-tool) | Scala a migliaia di strumenti scoprendo e caricando dinamicamente gli strumenti su richiesta utilizzando la ricerca basata su regex, ottimizzando l'utilizzo del contesto e migliorando l'accuratezza della selezione degli strumenti. | Claude API (Beta)<br>Amazon Bedrock (Beta)<br>Google Cloud's Vertex AI (Beta)<br>Microsoft Foundry (Beta) |
| [Web fetch](https://platform.claude.com/docs/it/agents-and-tools/tool-use/web-fetch-tool) | Recupera il contenuto completo da pagine web e documenti PDF specificati per un'analisi approfondita. | Claude API (Beta)<br>Microsoft Foundry (Beta) |
| [Ricerca web](https://platform.claude.com/docs/it/agents-and-tools/tool-use/web-search-tool) | Aumenta la conoscenza completa di Claude con dati attuali e reali da tutto il web. | Claude API<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
