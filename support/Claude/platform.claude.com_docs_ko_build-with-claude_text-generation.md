# 텍스트 생성

Copy page

Claude는 광범위한 텍스트 기반 작업에서 뛰어난 성능을 발휘합니다. Claude는 코드, 산문 및 기타 자연어 입력을 처리하고 이에 대한 응답으로 텍스트 출력을 제공하도록 훈련되었습니다.

Copy page

프롬프트는 누군가에게 무언가를 지시하는 것처럼 자연어 질의로 작성하는 것이 가장 좋으며, 세부 사항이 많을수록 좋습니다. [프롬프트 엔지니어링](https://platform.claude.com/docs/ko/build-with-claude/prompt-engineering/overview) 을 통해 기본 프롬프트를 더욱 개선할 수 있습니다.

* * *

## 텍스트 기능 및 사용 사례

Claude는 다음을 포함하되 이에 국한되지 않는 광범위한 텍스트 기반 기능을 보유하고 있습니다:

| 기능 | 이를 통해 다음을 할 수 있습니다... |
| --- | --- |
| 텍스트 요약 | 긴 콘텐츠를 경영진, 소셜 미디어 또는 제품 팀을 위한 핵심 인사이트로 압축합니다. |
| 콘텐츠 생성 | 블로그 게시물과 이메일부터 마케팅 슬로건과 제품 설명까지 매력적인 콘텐츠를 제작합니다. |
| 데이터 / 엔티티 추출 | 리뷰, 뉴스 기사 또는 대화록과 같은 비정형 텍스트에서 구조화된 인사이트를 발견합니다. |
| 질문 답변 | 고객 지원 챗봇부터 교육용 AI 튜터까지 지능적이고 상호작용적인 시스템을 구축합니다. |
| 텍스트 번역 | 제품, 지원 및 콘텐츠 제작에서 언어 간 원활한 소통을 가능하게 합니다. |
| 텍스트 분석 및 추천 | 감정, 선호도 및 패턴을 이해하여 사용자 경험과 제안을 개인화합니다. |
| 대화 및 대화형 상호작용 | 게임, 가상 비서 및 스토리텔링 앱에서 매력적이고 맥락을 인식하는 상호작용을 만듭니다. |
| 코드 설명 및 생성 | 즉시 코드 리뷰, 보일러플레이트 생성 및 대화형 튜토리얼로 개발을 가속화합니다. |
