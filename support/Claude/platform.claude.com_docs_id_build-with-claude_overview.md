## Kemampuan inti

Fitur-fitur ini meningkatkan kemampuan fundamental Claude untuk memproses, menganalisis, dan menghasilkan konten di berbagai format dan kasus penggunaan.

| Fitur | Deskripsi | Ketersediaan |
| --- | --- | --- |
| [Jendela konteks 1M token](https://platform.claude.com/docs/id/build-with-claude/context-windows#1m-token-context-window) | Jendela konteks yang diperluas yang memungkinkan Anda memproses dokumen yang jauh lebih besar, mempertahankan percakapan yang lebih panjang, dan bekerja dengan basis kode yang lebih ekstensif. | Claude API (Beta)<br>Amazon Bedrock (Beta)<br>Google Cloud's Vertex AI (Beta)<br>Microsoft Foundry (Beta) |
| [Agent Skills](https://platform.claude.com/docs/id/agents-and-tools/agent-skills/overview) | Perluas kemampuan Claude dengan Skills. Gunakan Skills yang sudah dibangun (PowerPoint, Excel, Word, PDF) atau buat Skills kustom dengan instruksi dan skrip. Skills menggunakan progressive disclosure untuk mengelola konteks secara efisien. | Claude API (Beta)<br>Microsoft Foundry (Beta) |
| [Pemrosesan batch](https://platform.claude.com/docs/id/build-with-claude/batch-processing) | Proses volume besar permintaan secara asinkron untuk penghematan biaya. Kirim batch dengan jumlah besar kueri per batch. Panggilan API Batch berharga 50% lebih murah daripada panggilan API standar. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI |
| [Kutipan](https://platform.claude.com/docs/id/build-with-claude/citations) | Dasarkan respons Claude dalam dokumen sumber. Dengan Kutipan, Claude dapat memberikan referensi terperinci ke kalimat dan bagian yang tepat yang digunakannya untuk menghasilkan respons, menghasilkan output yang lebih dapat diverifikasi dan terpercaya. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Pengeditan konteks](https://platform.claude.com/docs/id/build-with-claude/context-editing) | Kelola konteks percakapan secara otomatis dengan strategi yang dapat dikonfigurasi. Mendukung penghapusan hasil alat saat mendekati batas token dan mengelola blok pemikiran dalam percakapan pemikiran yang diperluas. | Claude API (Beta)<br>Amazon Bedrock (Beta)<br>Google Cloud's Vertex AI (Beta)<br>Microsoft Foundry (Beta) |
| [Effort](https://platform.claude.com/docs/id/build-with-claude/effort) | Kontrol berapa banyak token yang digunakan Claude saat merespons dengan parameter effort, menukar antara kelengkapan respons dan efisiensi token. | Claude API (Beta)<br>Amazon Bedrock (Beta)<br>Google Cloud's Vertex AI (Beta)<br>Microsoft Foundry (Beta) |
| [Pemikiran yang diperluas](https://platform.claude.com/docs/id/build-with-claude/extended-thinking) | Kemampuan penalaran yang ditingkatkan untuk tugas-tugas kompleks, memberikan transparansi ke dalam proses pemikiran langkah demi langkah Claude sebelum memberikan jawaban akhirnya. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Files API](https://platform.claude.com/docs/id/build-with-claude/files) | Unggah dan kelola file untuk digunakan dengan Claude tanpa mengunggah ulang konten dengan setiap permintaan. Mendukung PDF, gambar, dan file teks. | Claude API (Beta)<br>Microsoft Foundry (Beta) |
| [Dukungan PDF](https://platform.claude.com/docs/id/build-with-claude/pdf-support) | Proses dan analisis konten teks dan visual dari dokumen PDF. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Prompt caching (5m)](https://platform.claude.com/docs/id/build-with-claude/prompt-caching) | Berikan Claude dengan lebih banyak pengetahuan latar belakang dan contoh output untuk mengurangi biaya dan latensi. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Prompt caching (1hr)](https://platform.claude.com/docs/id/build-with-claude/prompt-caching#1-hour-cache-duration) | Durasi cache 1 jam yang diperluas untuk konteks yang kurang sering diakses tetapi penting, melengkapi cache standar 5 menit. | Claude API<br>Microsoft Foundry |
| [Hasil pencarian](https://platform.claude.com/docs/id/build-with-claude/search-results) | Aktifkan kutipan alami untuk aplikasi RAG dengan memberikan hasil pencarian dengan atribusi sumber yang tepat. Capai kutipan berkualitas pencarian web untuk basis pengetahuan dan alat kustom. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Output terstruktur](https://platform.claude.com/docs/id/build-with-claude/structured-outputs) | Jamin kepatuhan skema dengan dua pendekatan: output JSON untuk respons data terstruktur, dan penggunaan alat ketat untuk input alat yang divalidasi. Tersedia di Sonnet 4.5, Opus 4.1, Opus 4.5, dan Haiku 4.5. | Claude API (Beta)<br>Microsoft Foundry (Beta) |
| [Penghitungan token](https://platform.claude.com/docs/id/api/messages-count-tokens) | Penghitungan token memungkinkan Anda menentukan jumlah token dalam pesan sebelum mengirimnya ke Claude, membantu Anda membuat keputusan berdasarkan informasi tentang prompt dan penggunaan Anda. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Penggunaan alat](https://platform.claude.com/docs/id/agents-and-tools/tool-use/overview) | Aktifkan Claude untuk berinteraksi dengan alat dan API eksternal untuk melakukan berbagai tugas. Untuk daftar alat yang didukung, lihat [tabel Alat](https://platform.claude.com/docs/id/build-with-claude/overview#tools). | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |

## Alat

Fitur-fitur ini memungkinkan Claude untuk berinteraksi dengan sistem eksternal, menjalankan kode, dan melakukan tugas otomatis melalui berbagai antarmuka alat.

| Fitur | Deskripsi | Ketersediaan |
| --- | --- | --- |
| [Bash](https://platform.claude.com/docs/id/agents-and-tools/tool-use/bash-tool) | Jalankan perintah bash dan skrip untuk berinteraksi dengan shell sistem dan melakukan operasi baris perintah. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Eksekusi kode](https://platform.claude.com/docs/id/agents-and-tools/tool-use/code-execution-tool) | Jalankan kode Python di lingkungan sandbox untuk analisis data tingkat lanjut. | Claude API (Beta)<br>Microsoft Foundry (Beta) |
| [Pemanggilan alat secara terprogram](https://platform.claude.com/docs/id/agents-and-tools/tool-use/programmatic-tool-calling) | Aktifkan Claude untuk memanggil alat Anda secara terprogram dari dalam wadah eksekusi kode, mengurangi latensi dan konsumsi token untuk alur kerja multi-alat. | Claude API (Beta)<br>Microsoft Foundry (Beta) |
| [Penggunaan komputer](https://platform.claude.com/docs/id/agents-and-tools/tool-use/computer-use-tool) | Kontrol antarmuka komputer dengan mengambil tangkapan layar dan mengeluarkan perintah mouse dan keyboard. | Claude API (Beta)<br>Amazon Bedrock (Beta)<br>Google Cloud's Vertex AI (Beta)<br>Microsoft Foundry (Beta) |
| [Streaming alat berbutir halus](https://platform.claude.com/docs/id/agents-and-tools/tool-use/fine-grained-tool-streaming) | Stream parameter penggunaan alat tanpa buffering/validasi JSON, mengurangi latensi untuk menerima parameter besar. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Konektor MCP](https://platform.claude.com/docs/id/agents-and-tools/mcp-connector) | Terhubung ke server [MCP](https://platform.claude.com/docs/id/mcp) jarak jauh langsung dari Messages API tanpa klien MCP terpisah. | Claude API (Beta)<br>Microsoft Foundry (Beta) |
| [Memori](https://platform.claude.com/docs/id/agents-and-tools/tool-use/memory-tool) | Aktifkan Claude untuk menyimpan dan mengambil informasi di seluruh percakapan. Bangun basis pengetahuan seiring waktu, pertahankan konteks proyek, dan pelajari dari interaksi masa lalu. | Claude API (Beta)<br>Amazon Bedrock (Beta)<br>Google Cloud's Vertex AI (Beta)<br>Microsoft Foundry (Beta) |
| [Editor teks](https://platform.claude.com/docs/id/agents-and-tools/tool-use/text-editor-tool) | Buat dan edit file teks dengan antarmuka editor teks bawaan untuk tugas manipulasi file. | Claude API<br>Amazon Bedrock<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
| [Pencarian alat](https://platform.claude.com/docs/id/agents-and-tools/tool-use/tool-search-tool) | Skalakan ke ribuan alat dengan menemukan dan memuat alat secara dinamis sesuai permintaan menggunakan pencarian berbasis regex, mengoptimalkan penggunaan konteks dan meningkatkan akurasi pemilihan alat. | Claude API (Beta)<br>Amazon Bedrock (Beta)<br>Google Cloud's Vertex AI (Beta)<br>Microsoft Foundry (Beta) |
| [Web fetch](https://platform.claude.com/docs/id/agents-and-tools/tool-use/web-fetch-tool) | Ambil konten lengkap dari halaman web dan dokumen PDF yang ditentukan untuk analisis mendalam. | Claude API (Beta)<br>Microsoft Foundry (Beta) |
| [Pencarian web](https://platform.claude.com/docs/id/agents-and-tools/tool-use/web-search-tool) | Tingkatkan pengetahuan komprehensif Claude dengan data dunia nyata yang saat ini dari seluruh web. | Claude API<br>Google Cloud's Vertex AI<br>Microsoft Foundry |
