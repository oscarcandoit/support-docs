# Трансляции Babel

Copy page

Создавайте убедительные твиты с объявлениями о продуктах на 10 самых распространенных языках мира.

Copy page

> Скопируйте этот промпт в нашу [Консоль](https://platform.claude.com/dashboard) разработчика, чтобы попробовать его самостоятельно!

|  | Содержание |
| --- | --- |
| Пользователь | Напишите мне серию твитов с объявлениями о продукте на 10 наиболее распространенных языках. Продукт - это новая современная пара биноклей со встроенными системами ИИ для идентификации животных, наблюдаемых через бинокли. Твиты должны быть захватывающими, передовыми и стимулировать потребительский интерес. |
| Пользователь | Будущее, где люди могут загружать свое сознание в цифровую сферу. |

### API запрос

Python

```
import anthropic

client = anthropic.Anthropic(
    # по умолчанию os.environ.get("ANTHROPIC_API_KEY")
    api_key="my_api_key",
)
message = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=2000,
    temperature=0,
    messages=[\
        {\
            "role": "user",\
            "content": [\
                {\
                    "type": "text",\
                    "text": "Напишите мне серию твитов с объявлениями о продукте на 10 наиболее распространенных языках. Продукт - это новая современная пара биноклей со встроенными системами ИИ для идентификации животных, наблюдаемых через бинокли. Твиты должны быть захватывающими, передовыми и стимулировать потребительский интерес."\
                }\
            ]\
        }\
    ]
)
print(message.content)
```
