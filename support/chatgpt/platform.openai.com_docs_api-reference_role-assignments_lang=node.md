## Role assignments

Assign and remove roles for users and groups at the organization or project level.

## List group organization role assignments

gethttps://api.openai.com/v1/organization/groups/{group\_id}/roles

Lists the organization roles assigned to a group within the organization.

#### Path parameters

group\_id

string

Required

The ID of the group whose organization role assignments you want to list.

#### Query parameters

after

string

Optional

Cursor for pagination. Provide the value from the previous response's `next` field to continue listing organization roles.

limit

integer

Optional

A limit on the number of organization role assignments to return.

order

string

Optional

Sort order for the returned organization roles.

#### Returns

A list of [role objects](https://platform.openai.com/docs/api-reference/roles/object).

Example request

curl

```
1
2
3
curl https://api.openai.com/v1/organization/groups/group_01J1F8ABCDXYZ/roles \
  -H "Authorization: Bearer $OPENAI_ADMIN_KEY" \
  -H "Content-Type: application/json"

#### Path parameters

string

Required

The ID of the group that should receive the organization role.

#### Request body

role\_id

string

Required

Identifier of the role to assign.

#### Returns

The created [group role object](https://platform.openai.com/docs/api-reference/role-assignments/objects/group).

curl

```
1

  -H "Authorization: Bearer $OPENAI_ADMIN_KEY" \
  -H "Content-Type: application/json" \

## Unassign organization role from group

deletehttps://api.openai.com/v1/organization/groups/{group\_id}/roles/{role\_id}

Unassigns an organization role from a group within the organization.

#### Path parameters

group\_id

string

Required

The ID of the group to modify.

role\_id

string

Required

The ID of the organization role to remove from the group.

#### Returns

Confirmation of the deleted [group role object](https://platform.openai.com/docs/api-reference/role-assignments/objects/group).

Example request

curl

```
1
2
3
curl -X DELETE https://api.openai.com/v1/organization/groups/group_01J1F8ABCDXYZ/roles/role_01J1F8ROLE01 \
  -H "Authorization: Bearer $OPENAI_ADMIN_KEY" \
  -H "Content-Type: application/json"
```

Response

```
1
2
3
4
{
    "object": "group.role.deleted",
    "deleted": true
}
```

## Unassign project role from user

deletehttps://api.openai.com/v1/projects/{project\_id}/users/{user\_id}/roles/{role\_id}

Unassigns a project role from a user within a project.

#### Path parameters

project\_id

string

Required

The ID of the project to modify.

role\_id

string

Required

The ID of the project role to remove from the user.

user\_id

string

Required

The ID of the user whose project role assignment should be removed.

#### Returns
