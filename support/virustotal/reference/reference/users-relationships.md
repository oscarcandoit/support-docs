Users are related to other objects in our dataset. As mentioned in the [Relationships](/reference/relationships) section, those related objects can be retrieved by sending `GET` requests to this API endpoint.

Some relationships are only accessible to their account&#x27;s owners and their group&#x27;s admins.

The supported relationships are documented in the [User](/reference/user-object#relationships) API object page.
