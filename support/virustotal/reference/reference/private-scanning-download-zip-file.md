This endpoint is similar to [GET /private/zip_files/{id}/download_url](/reference/private-scanning-get-zip-download-url), but it redirects you to the download URL. The download URL you are redirected to can be reused as many times as you want for a period of 1 hour. After that period the URL expires and can&#x27;t be used anymore.
