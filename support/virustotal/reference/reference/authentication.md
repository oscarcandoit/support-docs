For authenticating with the API you must include the `x-apikey` header with your personal API key in all your requests. Your API key can be found in your VirusTotal account user menu:

![267](https://files.readme.io/ddeb298-Screen_Shot_2019-10-17_at_3.17.04_PM.png)

Your API key carries all your privileges, so keep it secure and don&#x27;t share it with anyone. Always use HTTPS instead of HTTP for making your requests.
