> 🚧
> ### Special privileges required[](#special-privileges-required)
> 
> 
> File feeds endpoints are only available to users with a File feeds license. For this particular endpoint, download file privilege is also required. [Contact us](https://www.virustotal.com/gui/contact-us/) for more information.
> 
> 

Each JSON object contained in the file feed packages include a URL to this API endpoint to download the corresponding file. The link only works during the feed&#x27;s lifetime, which is 7 days. Check [/feeds/files/{time}](/reference/feeds-file) for more information.
