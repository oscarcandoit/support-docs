This endpoint is the same as [/saved_searches/{id}/{relationship}](/reference/get-saved-searches-relationships) except it returns just the related object&#x27;s descriptor instead of returning all attributes.

Available relationships are described in the Saved Search object [Relationships](/reference/saved-search-object#relationships) section.
