Hunting Rulesets objects have relationships to other objects. As mentioned in the [Relationships](/reference/relationships) section, those related objects can be retrieved by sending `GET` requests to the relationship URL.

The relationships supported by Hunting Rulesets objects are documented in the [Hunting Rulesets](/reference/hunting-ruleset-object#relationships) API object page.
