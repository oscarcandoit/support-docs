File objects have many relationships to other files and objects. As mentioned in the [Relationships](/reference/relationships) section, those related objects can be retrieved by sending `GET` requests to the relationship URL.

Some relationships are accessible only to users who have access to VirusTotal Enterprise package.

More common relationships are described in the [File](/reference/files) object documentation and you can use the [metadata](https://docs.virustotal.com/reference/metadata) endpoint to get the full list of relationships.
